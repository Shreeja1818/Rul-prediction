# Remaining Useful Life (RUL) Prediction

A Python project that predicts how much working life a machine has left, using its sensor readings over time.

## What it does
- Reads machine sensor data
- Trains a model to learn how the machine wears out over time
- Predicts the Remaining Useful Life (RUL), which is the number of cycles left before failure
